# 御盾智核赛题三重任务适配说明

> 状态：DEV-026～030 P0 产品化验收 Gate（2026-08-10 更新）  
> 范围：只按真实实现更新证明状态，不把外部接口或后续规划写成已实现。

## 1. 总体结论

御盾智核属于“场景化安全智能体”：聚焦第三方 CI Action 异常导致 API 凭据泄露及云 API 滥用响应。当前已经能够通过真实 REST/SSE 和浏览器 UI，以受限 Agent、确定性 Policy、人工审批、Mock 动态状态、Verification 和 LangGraph 中断恢复连续完成 Guarded Golden Path。企业平台接入、RAG 和自治沙箱仍未实现。

## 2. 基础任务适配

### 2.1 场景化安全智能体

证明路径：Official PCAP/PCAP-NG → 可回查网络 Evidence → Monitoring Agent 调用确定性规则生成 Signal；Synthetic CI/云事件 → Main/Investigation/Trace Agent 形成 Task/Finding/Timeline → Fact Validator → Operation Agent 提出 Request → Policy/人工审批/受控执行/Verification/Audit。Agent 只能在 Evidence ACL 和 Tool Registry 内活动，不能直接执行。

### 2.2 深信服 AI 安全平台接入

当前状态：**【需要比赛方/企业方确认】**，尚未接入，也不宣称完成。

| 可接能力 | 建议 Adapter | 需要的接口 | 当前未知项 |
|---|---|---|---|
| 安全告警/事件查询 | `SangforAlertAdapter` | 告警查询 API、字段说明、分页和时间范围 | 产品型号、租户隔离、真实字段 |
| NTA/流量证据查询 | `SangforEvidenceAdapter` | 流/会话/原包定位接口 | packet locator 是否可回查 |
| 模型或智能分析能力 | `SangforModelAdapter` | 模型 API、认证、速率和数据出境约束 | 可用模型、Prompt/响应格式 |
| 处置建议或工单联动 | `SangforActionAdapter` | 动作白名单、审批/工单 API | 是否允许比赛环境写操作 |

接入原则：Adapter 把企业方返回值转换为现有 Schema；不得绕过 Evidence、Policy、审批或状态管理器。若比赛方仅提供模型接口，则只作为共享模型池能力，不能伪装成生产安全数据源。

## 3. 进阶任务适配

当前 Tool Registry、Evidence 查询、确定性 Timeline、Action Request、Policy、Mock Readback 与 Verification 属于工具能力扩展。P0 已实现 Agent 的真实受控工具调用链与拒绝审计；受控执行器仍只属于 SYSTEM_EXECUTOR。

Security Knowledge RAG **已实现**（`IMPLEMENTED`，2026-08-10）：它检索规则说明、处置手册和历史事件，相当于“安全知识搜索器”；检索结果只能作为参考材料或 EvidenceReference 之外的知识引用，不能直接成为攻击事实或授权依据。实现采用「SQLite FTS5 召回 + TF-IDF 重排」的离线确定性混合检索，知识库为内置 21 条 + `data/knowledge/` 可导入文档；以受控工具 `search_knowledge` 接入 Investigation Agent，命中记录在 Finding 的 `knowledge_refs` 并全程审计；并提供独立 REST API 与前端「Security Knowledge」工作区。详见 `docs/15-Security Knowledge RAG 实现文档.md`。未接真实向量 Embedding（离线优先），为可选增强。

## 4. 挑战任务适配

### 4.1 Auditable Reasoning Trace

不保存或展示模型私有隐藏推理。系统展示并审计结构化轨迹：

```text
Observation → Evidence → Task → Finding → Fact → Decision
→ Action → Observation → Replan
```

每个节点只展示输入引用、结构化输出、规则/权限结果和状态变化，结论必须回指 Evidence。当前已按 incident_id 从真实 Audit、Task、Finding、Fact、Policy、Execution 和 Verification 对象构建，不保存 Prompt 全文、秘密或隐藏 CoT。状态：**IMPLEMENTED**。

### 4.2 Competition Autonomous Sandbox

冻结两个运行模式；本批仅实现第一种：

- `PRODUCTION_GUARDED`：Policy → Human Approval → Controlled Execution；状态：**IMPLEMENTED（Mock/Sandbox 资源）**。
- `COMPETITION_AUTONOMOUS`：仅允许 Synthetic/Mock/Sandbox；Policy 预授权 → 受控执行 → Verification → Replan；状态：**IMPLEMENTED / SANDBOX ONLY**。连续三轮 E2E 均为 0 条 ApprovalRecord、1 条有效 PolicyPreAuthorization、3 步执行、6/6 验证、Audit VALID、CLOSED。

自治模式必须由环境配置和资源类型双重守卫，只能操作测试状态；真实生产资源、OFFICIAL 离线数据和任意脚本执行均不在自治授权范围。

### 4.2.1 AUTONOMOUS-SANDBOX-GAP

现有 `ApprovalRequirement` 只有人工审批和禁止两种语义，`ApprovalRecord` 也要求真实审批人。要实现零人工 Sandbox 分支，仍需冻结：`RunMode`、沙箱资源环境、Policy Pre-Authorization 记录、场景/动作白名单和审计语义。禁止用 `SYSTEM` 伪装人工审批。

### 4.3 Endpoint Minimal Event 决策

结论：**NOT REQUIRED**。

理由：现有 `CISecurityEvent` 已包含 repository、workflow、action digest 和 runner_ref，`SecretAccessEvent` 已表达同一 runner 对 credential_ref 的读取；二者通过 scenario_id、runner_ref、credential_ref 和时间可表达 `CI → Runner → Secret`。P0 不需要进程级检测或 Endpoint Agent，为赛题字面新增 `RunnerProcessEvent` 会扩大 Schema 和数据真实性负担，却没有新增官方数据证据。

只有当比赛方明确要求展示进程树，或后续真实端点数据包含 process_id、parent_process_id、command_line 且能形成 Evidence 时，才进入【待设计】评审。

## 5. 三重任务证明 Gate

| 任务 | 当前真实已实现 | 下一阶段尚缺 | 明确未完成 |
|---|---|---|---|
| 基础任务 | 场景化 Monitor/Main/Investigation/Trace/Operation/Audit 协同；REST/SSE；浏览器 Guarded Golden Path；三轮自动验收 | 真实 DeepSeek/Qwen smoke test | 深信服接口接入 |
| 进阶任务 | Agent 真实调用 Evidence/Timeline/Action 等受控工具；Tool ACL、调用审计和 UI 展示均生效 | 比赛讲解与材料固化 | Security Knowledge RAG（P1） |
| 挑战任务 | Auditable Reasoning Trace UI；验证失败可 Observe/Replan；Guarded interrupt/resume；Competition Autonomous Sandbox 零人工闭环 | DeepSeek/Qwen 真实 Provider 现场验证 | 隐藏 CoT 展示、真实生产零人工处置 |

Gate 结论：**PASS / P0 SCENARIO AGENT DEMO IMPLEMENTED**。`TOOL EXTENSION = IMPLEMENTED`；`AUDITABLE REASONING TRACE = IMPLEMENTED`；`OBSERVE / REPLAN = IMPLEMENTED`；`COMPETITION AUTONOMOUS SANDBOX = IMPLEMENTED / SANDBOX ONLY`。`SANGFOR PLATFORM INTEGRATION = PENDING EXTERNAL INTERFACE`；`SECURITY KNOWLEDGE RAG = P1 PENDING`。Guarded 路径继续要求人工审批，Autonomous 仅证明比赛沙箱内的技术自治能力。
