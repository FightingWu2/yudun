## 7. 当前已知风险

1. `App.tsx` 单文件 ~1088 行，无路由/状态库——最大可维护性技术债（已允许重构）。
2. 前端依赖用 `"latest"`，仅靠 lock 文件锁定（vite 8.2.1 / react 19.2.8 / ts 6.0.3）；换机器重装易漂移，建议固定版本。
3. `node_modules` 跨平台二进制不兼容（macOS/Linux 需各自 `npm ci` + `npx playwright install chromium`）。
4. SSE 是 0.25s 轮询式，非真推送。
5. `X-Demo-Role` 明文 header，仅本地演示隔离，非安全边界。
6. `data/`（257MB 官方 PCAP）不入 git；新环境需恢复数据集，否则 `start` 报 `SOURCE_UNAVAILABLE`。
7. `frontend/dist/` 不入 git；`make contest-preflight` 依赖 `dist/index.html`，新机器先 `npm run build`。
8. 深信服平台接入、Security Knowledge RAG、真实模型 live 验证未完成——UI 不得宣称已实现。
9. `.runtime/`（business.db / checkpoints.db）每次 `reset` 重建；不要在本地手改运行时库。
10. E2E 依赖稳定的 `data-testid` 与文案；改动需同步更新 `e2e/*.spec.ts`。
